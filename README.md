# plane-marketplace-operator

A Kubernetes operator (Go) that manages the lifecycle of marketplace applications
on an **edge fleet** — e.g. aircraft with intermittent connectivity — and keeps
them in sync with a **cloud control plane on AWS**.

Built with [Kubebuilder](https://book.kubebuilder.io) / controller-runtime, the
Helm SDK and the AWS SDK for Go v2.

---

## Overview

Each aircraft runs a lightweight Kubernetes cluster (K3s). Applications
(marketplace offerings) are declared as `AppRelease` custom resources:

```yaml
apiVersion: marketplace.edge-ops.dev/v1alpha1
kind: AppRelease
metadata:
  name: streaming-film
spec:
  appName: streaming-film
  version: "2.4.0"                  # desired version
  source: s3://<bucket>/charts/demo-app-0.1.0.tgz
  digest: sha256:e41bd4e6...        # integrity check
status:
  installedVersion: "2.4.0"         # written by the operator only
  conditions:                       # Ready / Progressing / Failed
    - type: Ready
      status: "True"
      reason: Installed
```

The operator converges **actual → desired** state: download from S3, verify the
SHA-256 digest, install/upgrade with Helm, report back through status conditions.
Everything is idempotent and safe to replay — a requirement when the network can
disappear at any moment.

## Architecture

```
┌──────────────────────── CLOUD (AWS) ────────────────────────┐
│  S3 bucket (versioning ON)      marketplace-artifacts-<acct>│
│  SQS FIFO marketplace-desired.fifo   (commands cloud → edge)│
│  SQS FIFO marketplace-status.fifo   (reports edge → cloud)  │
│  IAM user edge-operator (least privilege: read bucket,      │
│       send status, receive desired — nothing else)          │
└─────────────────────────────────────────────────────────────┘
        ▲  intermittent connectivity
        ▼
┌──────────────────────── EDGE (aircraft) ────────────────────┐
│  K3s cluster (k3d "a380-01" locally)                        │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ Operator (this repo)                                │    │
│  │  AppRelease CR ──▶ Reconcile loop:                  │    │
│  │    fetch S3 → sha256 verify → Helm install/upgrade  │    │
│  │    → write status (conditions + installedVersion)   │    │
│  │  Atomic=true ⇒ failed upgrade rolls back to previous│    │
│  └─────────────────────────────────────────────────────┘    │
│  edge-agent (next milestone)                                 │
│     poll desired.fifo → materialize CRs                     │
│     watch CR status → publish to status.fifo                │
│     exponential backoff + resync on reconnection            │
└─────────────────────────────────────────────────────────────┘
```

## How reconciliation works

1. **Get** the `AppRelease` CR (fresh from the API).
2. **Drift check** — `spec.version != status.installedVersion`? No drift → set
   `Ready/UpToDate` and stop (idempotence: replaying a no-op is a no-op).
3. **Progressing** condition is published so the cloud can observe progress.
4. **Download** the chart from `spec.source` (parsed as `s3://bucket/key`) into a
   local artifact cache — the artifact stays available on the aircraft after the
   link goes down.
5. **Verify** SHA-256 of the received file against `spec.digest`.
   - Mismatch → `Failed/DigestMismatch`, file discarded, **running app untouched**.
     This is a *permanent* error: no requeue storm.
6. **Install/upgrade** with the Helm SDK (`History` → `Install` or `Upgrade`),
   `Atomic=true` so a failed upgrade rolls back to the previous release.
   - Failure → `Failed/InstallError`, retried by controller-runtime with backoff.
7. **Close the loop** — `status.installedVersion = spec.version`, `Ready/Installed`.

Status updates go through `client-go`'s `RetryOnConflict` to stay safe against
informer cache lag (classic 409 pattern in operators).

## Getting started

### Prerequisites

- Go 1.26+, Docker, kubectl, Helm 3
- [k3d](https://k3d.io) (local edge cluster), [kubebuilder](https://book.kubebuilder.io) v4
- Terraform + an AWS account (S3/SQS cost ≈ $0 for this scale)

### 1. Local cluster (the "aircraft")

```sh
k3d cluster create a380-01 --servers 1 --agents 1
kubectl config use-context k3d-a380-01
kubectl create namespace marketplace
```

### 2. Cloud resources (Terraform)

```sh
cd infra
terraform init && terraform plan && terraform apply
# exports the edge-operator IAM access keys (sensitive)
```

The IAM policy is strictly least-privilege: `s3:GetObject`/`s3:ListBucket` on the
bucket, `sqs:SendMessage` on the status queue, `sqs:ReceiveMessage`/`DeleteMessage`
on the desired queue. The asymmetry is deliberate — an edge device cannot publish
commands or read other aircrafts' reports.

### 3. AWS credentials for the operator

```sh
export AWS_ACCESS_KEY_ID=<edge key> AWS_SECRET_ACCESS_KEY=<edge secret> AWS_DEFAULT_REGION=us-east-1
unset AWS_PROFILE   # never run the operator with an admin profile
```

### 4. Install the CRD and run

```sh
make manifests && make generate && make install
kubectl apply -f config/samples/marketplace_v1alpha1_apprelease.yaml
make run
```

### 5. Publish a real artifact

```sh
helm package charts/demo-app -d /tmp
aws s3 cp /tmp/demo-app-0.1.0.tgz s3://<bucket>/charts/
sha256sum /tmp/demo-app-0.1.0.tgz   # → update spec.digest
```

## Demo scenarios

| # | Scenario | Expected behaviour |
|---|---|---|
| T1 | Create CR → app installed | Pod appears in `marketplace`, `installedVersion` set, `Ready` |
| T2 | Bump `spec.version` | Helm release revision increments, new version running |
| T3 | Corrupt the S3 artifact, bump version | `Failed/DigestMismatch`, running app **not** degraded |
| T4 | Restore artifact + revert version | Clean rollback to the previous version |
| T5 | *(next milestone)* disconnect/reconnect the edge-agent | Messages replayed exactly once, statuses caught up |

## Design decisions

- **Operator over cronjob/script**: declarative desired state, self-healing
  reconciliation, standard CRD tooling; "install v2.4.0" is state, not a script.
- **SQS FIFO + content-based deduplication**: an unreliable satellite link
  retransmits a lot — deduplication guarantees a command applies exactly once,
  ordering guarantees v1 is applied before v2.
- **SHA-256 pinned in the spec**: integrity is verified on the aircraft at
  install time; a corrupted transfer is refused instead of installed.
- **Atomic Helm upgrades**: a failed install rolls back to the previous release —
  the aircraft is never left degraded.
- **Versioned S3 bucket**: artifact history is preserved, enabling rollbacks.
- **Least-privilege IAM with asymmetric queues**: blast radius of a compromised
  edge credential is bounded to read-artifacts + report-status.

## Known SDK gotchas (learned while building)

- Helm SDK `Upgrade.Run` does **not** install missing releases (`--install` is a
  CLI-layer feature): branch on `History()` yourself.
- The namespace passed to `action.Configuration.Init` only affects release
  *storage*; call `settings.SetNamespace(ns)` or the Kubernetes client applies
  resources in the kubeconfig context namespace.
- `NewInstall`/`NewUpgrade` default `Timeout` is 0 — set it explicitly or
  `Atomic=true` fails instantly with `context deadline exceeded`.
- `client.RetryOnConflict` moved out of controller-runtime: use
  `k8s.io/client-go/util/retry`.

## Security notes

- No secrets in this repository: `infra/terraform.tfstate*` and `.terraform/`
  are gitignored (state contains IAM keys).
- Rotate the `edge-operator` access key if it was ever exposed
  (`terraform taint aws_iam_access_key.edge_operator && terraform apply`).
